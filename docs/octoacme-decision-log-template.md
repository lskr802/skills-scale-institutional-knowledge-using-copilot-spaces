# OctoAcme — Decision Log Template

## Purpose
Capture key decisions so context is not lost and future teammates can understand the “why”.

## How to use
- Create one decision entry per meaningful decision.
- Link to issues/PRs/design docs when available.
- Keep it short; record just enough to reconstruct the reasoning.

## Decision entry template
- **Decision ID:** (e.g., DEC-001)
- **Date:** (YYYY-MM-DD)
- **Decision owner:** (name/role)
- **Participants:** (optional)
- **Context:** What problem are we solving?
- **Decision:** What did we choose?
- **Options considered:** (bullets)
- **Rationale:** Why this option?
- **Consequences / follow-ups:** What changes because of this?
- **Links:** (issues, PRs, docs, dashboards)

## Example
- **Decision ID:** DEC-001
- **Date:** 2026-04-18
- **Decision owner:** TL
- **Context:** We need predictable release rollbacks.
- **Decision:** Adopt an incident & rollback checklist in the repo.
- **Rationale:** Reduces outage time and confusion under pressure.
- **Links:** (add link)
