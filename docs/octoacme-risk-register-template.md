# OctoAcme — Risk Register Template

## Purpose
Standardize how we capture and manage risks so they are visible, owned, and reviewed regularly.

## How to use
- Review weekly (or at each milestone).
- Assign an owner for every risk.
- Close risks explicitly when no longer relevant.

## Risk table (copy/paste)

## Notes
- “Mitigation” reduces probability/impact.
- “Contingency” is what we do if it happens.
- Link risks to issues when mitigation work is planned/tracked.
